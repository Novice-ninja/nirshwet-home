# Validation history

These are observations from the original LG 50UP7670PUC, not a claim of compatibility with other TVs. Hardware validation was performed on October 19, 2026 using the original private namespace. The public Sofa Goblin identifiers were renamed afterward; that renamed build has not been installed on the original TV. Public repository preparation does not deploy changes to the TV.


`tests/browser-check.js` is an executable function for the Playwright browser tool (pass its absolute path as `filename`, while the preview server is running). It checks remote navigation and boundaries, Back confirmation, focus trapping, reorder persistence and cancellation, damaged local storage, 1080p/720p layout, exact launch IDs, failure/timeout recovery, duplicate-launch prevention, and the photo cycle/suspend/resume behavior.

The browser checks passed with a **simulated** PalmServiceBridge. Syntax checks and LG package generation passed. A private photo collection was imported and checked for decoding and orientation; no personal photos or screenshots are included in this repository.

Version **0.1.1** was installed on the actual TV on October 19, 2026. Its live inspector confirmed a visible 1920 × 1080 layout, five tiles, the bundled Nunito Sans font, and a decoded local photo. A screenshot from the TV confirmed the rendered layout. Activating the launcher's YouTube tile brought `youtube.leanback.v4` to the foreground, verified through the TV's app-status API, and the launcher reopened afterward. Physical remote behavior, the remaining four app transitions, and photo smoothness still need user validation; no TV performance benchmark has been completed.

The initial 0.1.0 install displayed a black screen because this TV's browser rejected bundled `file:` assets under a CSP allowing only `'self'`. Version 0.1.1 explicitly allows local `file:` scripts, styles, fonts, and images while keeping network connections disabled. Validate packaged apps on the TV, since an HTTP browser preview did not reproduce this issue.

Version **0.1.2** replaces all five text/CSS logo approximations with artwork from the services' official websites. The local preview and actual TV were visually checked. The TV inspector confirmed all five logo files decoded, retained their proportions, and fit within their tiles at 1920 × 1080. The update was installed and opened on the TV.

Version **0.1.3** applies the Soft Morning pastel palette to the background, cards, controls, confirmation dialog, notifications, photo frame, and app icon. Primary text has at least 7.00:1 contrast against the palette's base colors, secondary text 4.70:1, and focus outlines 4.77:1. The confirmation dialog was visually checked in the preview. On the actual TV, the updated background, all five logos, a photo, and focus border rendered at 1920 × 1080 with no page overflow. The background adds only static CSS gradients, with no animation or image downloads.

Version **0.1.4** adds the intentional LG Home bypass for the rooted Home manager. On October 19, 2026, the manager was installed and checked on this TV: a Home remote command returned from YouTube to the launcher; the launcher's actual confirmation action opened LG Home and stayed there; disabling the manager restored normal LG Home; and a real system reboot restored root SSH and automatically foregrounded the launcher. Saved launcher preferences survived. The six policy tests cover startup, ordinary app transitions, the LG Home bypass, standby/wake handling, bounded failures, disable/stop, and duplicate prevention. A single idle measurement showed about 9.4 MiB RSS for the manager, excluding its two small Luna subscription processes; this is not a performance benchmark. The user also confirmed that the launcher opened automatically after turning the TV off with the physical remote, waiting 10 seconds, and turning it on again.

Version **0.1.5** adds the remote guard and its launcher control. All eight guard policy tests, the six Home manager tests, syntax checks, and packaging passed. On the actual TV, simulated events sent through the physical input device verified that single presses of all eight protected keys stayed in YouTube, two Home presses returned to the launcher, and two Prime presses opened Prime Video. An arrow moved focus while the filter was active. The launcher's actual Turn off and Turn on controls changed the running filter state successfully; its 1920 × 1080 layout was checked with no horizontal overflow. Deliberately stalling the filter verified watchdog recovery and release of the original remote. A full system reboot restarted the guard and foregrounded the launcher. The user confirmed that physical arrows and the protection work. The square-with-outward-right-arrow button beside Right emits **Exit (174)**; it had previously been called Source during setup. An isolated comparison confirmed that one unfiltered Exit and two guarded Exit presses both leave YouTube for LG Home. The existing Home manager then opens the launcher; the guard preserves the Exit code. Physical Source/Input (241) and every shortcut input path have not been individually calibrated.

Version **0.1.6** deepens the Soft Morning palette, strengthens forest-green accents, removes the pure-white YouTube tile surface, and enlarges the title, clock, and date. Primary text has at least 5.72:1 contrast, secondary text 4.64:1, and accents 4.72:1 against the palette's base colors. Browser checks covered 1080p/720p layout, header/photo spacing, arrow focus, and the Back dialog. Syntax checks and packaging passed. Installed on the TV: its inspector confirmed the new gradients, 43.2 px title, 54.72 px clock, 25.92 px date, five decoded logos, a decoded photo, Guard: On, and no page overflow at 1920 × 1080. The update adds no timers, services, dependencies, or network requests.

**Home-button correction (October 19, 2026):** The previous native-Home redirect reproduced multiple LG/custom-launcher transitions from a single input test. The guard now sends accepted Home presses directly to the existing manager, suppressing the native Home key and its held repeats. The manager uses one launch, treats an unclosable LG overlay as nonfatal, and withdraws direct-routing capability if automatic launching stops. All 11 Home manager and 11 guard tests passed. TV tests through the calibrated physical input device verified no LG transitions from tapping/holding Home on the launcher, first-press blocking in YouTube, direct return on the second press, and intentional LG Home access followed by a single clean return. Installed support files persist across startup; the launcher package remains 0.1.6. The previous support files were backed up locally before deployment.

Run photo import in a normal macOS terminal. In a restricted automation sandbox, ImageIO can silently produce black pixels; preview the outputs and permit local image decoding outside that sandbox when necessary. The source photos are read-only inputs.

## Public source validation

On October 25, 2026, an isolated copy containing only publishable files passed syntax checks, all 25 Home/guard/config tests, and IPK packaging after a fresh dependency install. It contained no imported photos or private device configuration. SSH configuration parsing was checked with OpenSSH, including paths containing spaces. These checks did not modify the TV.
